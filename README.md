# Minesweeper AI

A C++ Minesweeper AI that automatically solves boards using logical inference and probability-based decision making.

## Features
- Identifies guaranteed safe tiles and mines
- Uses neighboring tile constraints to make decisions
- Applies probability-based reasoning when no guaranteed move is available
- Automatically plays through Minesweeper boards

## Technologies
- C++
- STL data structures including vectors, sets, maps, and queues

## Running the Project
Follow the instructions in the included project documentation to compile and run the Minesweeper environment.
